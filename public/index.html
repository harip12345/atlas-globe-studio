QUICK START

Dari ide ke video.

  1. Pilih template atau tulis narasi.

    Tab Narasi menyusun satu adegan per paragraf dan mengenali nama lokasi.

  2. Atur lokasi, kamera, dan objek.

    Pilih adegan di kiri. Jarak kamera menentukan zoom. Kamera bergerak dari tujuan adegan sebelumnya ke tujuan adegan aktif.

  3. Cocokkan dengan voice-over.

    Unggah audio di tab Audio. Ubah durasi adegan agar sesuai ucapan. Subtitle mengikuti teks narasi per adegan.

  4. Putar, simpan, lalu ekspor.

    Tombol spasi untuk play/pause. Simpan JSON untuk melanjutkan. Pilih Full HD untuk hasil akhir 9:16.

Tekstur bumi adalah citra global. Detail dekat memakai objek 3D ilustratif; belum memakai citra jalan atau bangunan fotogrametri.
